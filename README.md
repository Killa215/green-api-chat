# GREEN-API Chat на React

Тестовое задание на должность «Фронтенд разработчик React».
Веб-приложение для отправки и получения текстовых сообщений через
мессенджер MAX с использованием GREEN-API.

## 🔧 Стек

- **React 18** + **Vite**
- **JavaScript (ES2020+)**
- **GREEN-API v3** (HTTP API)
- **localStorage** для сохранения чатов и сообщений

## ✅ Что реализовано

- Авторизация по `idInstance` и `apiTokenInstance`
- Отправка сообщений методом **SendMessage**
  (`https://green-api.com/v3/docs/api/sending/SendMessage/`)
- Получение сообщений методом **ReceiveNotification**
  (`https://green-api.com/v3/docs/api/receiving/technology-http-api/`)
- Создание чата по номеру телефона
- Автоматическое объединение чатов:
  при ответе получателя временный чат-номер заменяется
  на реальный `chatId` из системы MAX
- Загрузка истории чата (`GetChatHistory`)
- Список чатов (`GetChats`)
- Контекстное меню с удалением чата
- Сохранение всех данных в `localStorage`
- Защита от ошибки `429 Too Many Requests`

## 🚀 Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ваш_аккаунт/green-api-chat.git
cd green-api-chat
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Запустить dev-сервер

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`.

### 4. Получить данные инстанса GREEN-API

1. Зарегистрируйтесь на [green-api.com](https://green-api.com).
2. Создайте инстанс.
3. Скопируйте `idInstance` и `apiTokenInstance`.
4. Убедитесь, что статус инстанса — **«Авторизован»**.
5. В настройках инстанса включите:
   - `incomingWebhook` — для входящих
   - `outgoingWebhook` — для исходящих
   - `outgoingAPIMessageWebhook` — для исходящих через API
   - Поле `webhookUrl` должно быть **пустым**.

### 5. Войти в приложение

Введите `idInstance` и `apiTokenInstance` в форму входа.
Создайте чат, введя номер получателя — и начните переписку.

## ⚠️ Особенности

- **HTTP API, а не Webhook** — согласно требованиям ТЗ,
  используется метод `ReceiveNotification` в цикле (поллинг).
- **Автоудаление временного чата-номера** — при получении
  первого входящего сообщения от реального `chatId` приложение
  удаляет чат-номер и переключается на чат с корректным ID.
- **Задержка поллинга** — 5 секунд, с автоувеличением при
  ошибках до 30 секунд (защита от `429`).
